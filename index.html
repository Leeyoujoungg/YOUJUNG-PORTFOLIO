검사하며 고친 것

  1. 연락처 주소 글자 크기칸 폭에 맞춰 글자를 줄이려고 쓴 컨테이너 쿼리(container-type, cqi)를 검사기가 인식하지 못해 오류 3개 → 화면 폭(vw) 기준 계산으로 바꿔, 320px~2560px 모든 폭에서 주소가 한 줄로 들어가는 것을 다시 확인
  2. 프로젝트 카드<article role="link">는 표준 오류 → 카드 제목에 실제 링크 <a href>를 넣고 클릭 영역을 카드 전체로 넓혀, 키보드와 화면낭독기에서도 일반 링크로 동작하게 수정
  3. 말모이 슬라이더역할 없는 div의 aria-label 오류 → role="region"을 더해 WAI-ARIA 캐러셀 패턴으로 수정
